DJ FUEL WEBDECK v0.3 Folders

Adds custom virtual folders, selectable tracks, batch move, rename/delete folder without deleting audio.
Preserves the v0.2 Fade Fix, IndexedDB music storage, deck functions and cue/comments.

Upload index.html, manifest.webmanifest and sw.js to the GitHub Pages repository root.
Note: folder names and assignments are stored in localStorage in the same browser app installation.
Always keep original MP3 backups and test audio and offline behavior before live use.
